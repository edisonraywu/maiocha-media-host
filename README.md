# maiocha-media-host

Temporary public media assets for approved Instagram publishing campaigns.

Only approved campaign media and a public integrity manifest belong here. Secrets, source projects, drafts, logs, tokens, cookies, and local configuration are prohibited.

Current campaign assets are stored under `media/maiocha-launch-2026-09-16/` for GitHub Pages delivery.


## Multi-brand automation

This repository also versions the baobao automation engine and scoped legacy safety updates. The repository name is historical; existing maiocha campaign media paths are retained, while baobao uses `media/baobao/{content_id}/`. Private product intake, previews, profiles, credentials and approval workspaces are not committed.

See [daily use](docs/baobao-automation.md), [caption calibration](docs/baobao-caption-calibration.md), and [multi-brand isolation](docs/multi-brand-isolation.md). Deploying code never resumes paused Instagram production.

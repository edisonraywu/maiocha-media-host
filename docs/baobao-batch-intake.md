# 下一批照片怎麼給我

每週或每兩週，把每條素串約六張照片交給 Codex，說「處理這批寶寶礦照片」。直接像這樣說就好，不用寫 YAML：

> 這批排 10/1～10/14。
>
> BB001：海藍寶，10/1，附這條的六張照片。
>
> BB002：綠碧璽，10/2，附這條的六張照片。
>
> BB003：紫水晶，10/3，附這條的六張照片。

水晶名稱與照片對應由你決定。價格、珠徑、SKU、庫存、備註可選填；某篇另有時間也可直接說。沒有另訂時間就用已保存的每日預設。

我會整理資料夾、逐商品讀圖、寫 A／B／C、QA、選封面、排輪播，給你整批 Preview。若某筆身分、照片對應或日期不清楚，只補問那筆。

看完可說「BB003 換 B」或「BB005 第一張跟第三張交換」。只有你說「10/1～10/5 可以發」才批准那些商品；給照片與指定日期都不等於批准。
